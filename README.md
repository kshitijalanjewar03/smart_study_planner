# Smart Study Planner

**Plan Smarter. Study Better. Achieve More.**

## About the Project

Smart Study Planner is a web-based application designed to help students organize their studies, manage academic tasks, and track their learning progress efficiently. It allows students to create study schedules, set priorities, manage deadlines, and stay focused on their academic goals.

The main objective of this project is to make study planning simple, organized, and productive through an easy-to-use interface.

## Objectives

- Organize daily and weekly study schedules.
- Manage subjects, assignments, and upcoming exams.
- Prioritize important tasks and deadlines.
- Track completed and pending study tasks.
- Improve time management and productivity.
- Provide a clean, responsive, and user-friendly dashboard.

## Features

- **Dashboard:** View study tasks, upcoming deadlines, and overall progress.
- **Task Management:** Add, edit, delete, and complete study tasks.
- **Study Timetable:** Organize study sessions by subject, date, and time.
- **Priority Management:** Categorize tasks into High, Medium, and Low priority.
- **Progress Tracking:** Monitor completed tasks and pending activities.
- **Deadline Management:** Highlight upcoming tasks and important deadlines.
- **Responsive Design:** Access the planner on desktops, tablets, and mobile devices.
- **Data Persistence:** Save study tasks locally using browser storage, if implemented.

## Technologies Used

- **HTML5:** Structure of the application.
- **CSS3:** Styling, layout, and responsive design.
- **JavaScript:** Task management, interactions, and progress calculations.
- **Local Storage:** Saving tasks in the browser, if implemented.

## Getting Started

Follow these steps to run the project locally.

### Prerequisites

- A modern web browser such as Google Chrome.
- A code editor such as Visual Studio Code.
- Basic knowledge of HTML, CSS, and JavaScript.

### Installation

1. Clone the repository:

   ```bash
   git clone 
   ```

2. Navigate to the project directory:

   ```bash
   cd smart-study-planner
   ```

3. Open the project in Visual Studio Code.

4. Open `index.html` in your browser or use the Live Server extension.

## How to Use

1. Open the Smart Study Planner application.
2. View your study dashboard.

5. Mark tasks as completed when finished.
6. Review your progress and organize upcoming study sessions.
